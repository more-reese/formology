# Starting Core — H1–H7

*As given. These are hypotheses, not settled claims.*

**H1.** Form is what stays the same when the instance changes. [AFFIRMED]

**H2.** Form gets its meaning from a declared context. Before a context is declared, form is complete but undetermined (a "proformation"). Once a context is declared, it is resolved (a "conformation"). Example: a note on a staff with no key signature, then with one. [AFFIRMED]

**H3.** Context does the resolving; form is what gets resolved. Context is defined as what form is not. [AFFIRMED]

**H4.** Something counts as form only if it (a) occupies a structural slot, (b) stands in for something recoverable, and (c) gets its meaning from context rather than from itself. All three must hold. [AFFIRMED]

**H5.** Recursion: a resolved form is itself a form at the next level up. There is no ground level. [AFFIRMED]

**H6.** Resolution can be reversed by withdrawing the context. [AFFIRMED]

**H7.** Form cannot be proven, since proof requires form. It is posited, and confirmation happens in practice. [AFFIRMED]

## Known Issues

1. **Disjointness vs. recursion:** Proformation and conformation are declared disjoint in the OWL ontology, but H5 says a resolved form is itself a form at the next level. This is a contradiction unless "level" is added as a parameter — i.e., proformation and conformation are disjoint *at the same level* but a conformation at level N is a proformation at level N+1.

2. **H4 vs. pro-form definition:** H4's three conditions (structural slot, substitution, anaphoric interpretation) are nearly the textbook definition of a linguistic pro-form. If "form" and "proformation" both reduce to "pro-form," then the distinction between them collapses, and the prefix axis (pro-/con-) adds nothing beyond what linguistics already has.

3. **Etymology error:** The treatise's form/firm etymology is incorrect. This does not affect the hypotheses but should be corrected in any derivative claims.

4. **H3 boundary:** "Context is defined as what form is not" creates a binary (form / not-form). If context is itself a form at a higher level (per H5), then the binary is level-dependent: context is not-form *locally* and form *globally*. This is coherent but means H3 is a local claim, not a global one.
